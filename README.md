#### Projects

- [**hearloom**](https://github.com/wynn-dev/hearloom): I wanted the Omi pendant's always-on audio memory without sending every second of my day to someone else's cloud. Now it streams to my own server as a searchable timeline.
- [**whoop-dashboard**](https://github.com/wynn-dev/whoop-dashboard): the WHOOP app didn't let me look at my data the way I wanted. This is my own dashboard for it, with an MCP server so my AI assistant can read it too.
- [**cliproxyapi-console**](https://github.com/wynn-dev/cliproxyapi-console): CLIProxyAPI is managed through raw YAML. I wanted history, account limits at a glance, and one command to set it all up.
- [**brightspace-mcp-server**](https://github.com/wynn-dev/brightspace-mcp-server): clicking through Brightspace to find grades and deadlines got old, so now I just ask my AI. Built on [Rohan Muppa's](https://github.com/RohanMuppa/brightspace-mcp-server) project, with TU Delft login added.
- [**light-bench**](https://github.com/wynn-dev/light-bench): every new VM meant a different set of benchmark commands and numbers I couldn't compare. Now it's one script and a summary I can diff between machines.
